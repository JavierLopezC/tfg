\chapter{Conclusiones y trabajo futuro\label{sec:conclusiones}}

\section{Conclusiones}
Durante el desarrollo de este trabajo se ha implementado en el programa \textbf{OncoSimulR} un módulo para permitir la creación y tratamiento de variables arbitrariamente complejas definidas por el usuario para tracear durante la simulación. Además se ha ampliado la funcionalidad que ya existía para simulación de intervenciones y tratamientos, permitiendo que estas empleen las variables de usuario creadas, logrando así reproducir conjuntos complejos de tratamientos aplicables en función de la evolución del conjunto de células tumorales, es decir, se ha permitido emular la terapia adaptativa.

Desde un punto de vista académico, este trabajo ha permitido al autor familiarizarse y sentirse cómodo con los lenguajes R y C++ que no dominaba, así como ampliar su conocimiento acerca de algoritmos genéticos, y aprender sobre los algoritmos específicos de simulación tumoral. Además, ha permitido que este adquiera nociones básicas de genética y medicina relacionadas directamente con los procesos tumorales, abriéndolo a un posible campo de interés en el futuro.

\section{Líneas de trabajo futuro}

La funcionalidad desarrollada en este proyecto abre camino a una serie de posibles mejoras y funcionalidad futura. Algunas posibles mejoras que se podrían plantear son:

\begin{itemize}
	\item Ampliar el número de variables que se pueden emplear para definir las variables de usuario, haciéndolas aún más libres y permitiendo prácticamente cualquier función que se le pueda ocurrir al usuario.
	\item Implementar funciones para representar gráficamente de forma eficiente los valores en el tiempo de las variables de usuario, puesto que por el momento, la salida es simplemente en forma de tabla de datos y realizar una gráfica con estos es ligeramente engorroso.
\end{itemize}
